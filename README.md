# Monitoring logs in Azure


What I Did
- Explored Azure Monitor to track activities and changes within an Azure account.
- Reviewed Activity Logs to monitor security-related events, policy changes, and resource activity.
- Configured Diagnostic Settings to export Activity Logs.
- Selected the available log categories and created a named diagnostic setting.
- Navigated to the Queries Hub and explored running Azure Activity Log queries.

Project Summary
Learned how Azure Monitor tracks account activity and how Activity Logs can be exported and queried for visibility into resource changes, security events, and administrative actions.

Future Learning Goals
I plan to continue practicing Azure Monitor, explore additional KQL queries, and learn how to use activity logs to investigate suspicious changes and support security monitoring.
